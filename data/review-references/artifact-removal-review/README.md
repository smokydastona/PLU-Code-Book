# Artifact-removal candidates

These are unapproved review-only derivatives of images embedded in
`data/review-references/Produce_Image_Review_Checked_2026-11-21.pdf`.
The 120 x 120 source images were taken from the owner's checked review PDF,
not from the original high-resolution image files. Only detached marks at the
bottom were removed; no missing produce was reconstructed.

`outputs/review-booklets/PRODUCE_IMAGE_UNCHECKED_REVIEW.csv` records the
original image hashes, WorkingList identities, derivative hashes, and edits.
The images still require owner review and are not production assignments.
Resolution, rights, provenance, and other publication checks remain required.
